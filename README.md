# Growviax Global 🌍

**Growviax Global** is a premium international corporate export company specializing in high-quality agricultural products. We connect local farmers producing premium ingredients with international markets, operating with complete transparency and ensuring all products meet the highest global standards.

## 🚀 Key Features
- **Modern & Premium Design**: Features a highly aesthetic, trending glassmorphism UI with smooth micro-animations.
- **Fully Responsive**: Optimized for flawless viewing across desktops, tablets, and mobile devices.
- **Interactive UI Components**: Utilizes smooth scrolling, Swiper carousels, and fade-in animations on scroll.
- **Optimized for SEO**: Standardized meta tags, open-graph tags, and semantic HTML structure.

## 📦 What We Export
- **Spices**: Turmeric Powder, Chilli Powder, Cumin Seeds, Coriander Seeds, and more.
- **Dehydrated Products**: Onion Flakes/Powder, Garlic Flakes/Powder, Ginger Powder.
- **Dairy Products**: Skimmed Milk Powder, Desi Ghee.
- **Honey & Fresh Produce**: Pure Honey, Fresh Onions.

## 🛠️ Tech Stack
- **HTML5 & CSS3**
- **Bootstrap 5** (Layout and core styling)
- **Vanilla JavaScript** (Logic and interactivity)
- **Phosphor Icons** (Modern iconography)
- **AOS (Animate On Scroll)** (Scroll animations)
- **Swiper.js** (Product carousels and sliders)
- **Lenis** (Smooth scroll)
- **GLightbox** (Image galleries)

## 🌐 Running Locally
Since this is a static website, you can view it by simply opening the `index.html` file in any modern web browser.
Alternatively, use a local server for the best experience (especially for fetching local assets without CORS issues):

```bash
# Using VS Code Live Server Extension
Right-click index.html -> "Open with Live Server"

# Using Node.js (http-server)
npx http-server ./

# Using Python
python -m http.server 8000
```
